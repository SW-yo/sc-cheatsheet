### 1. 最重要：必ず覚えるべき基本ポート

| ポート番号       | プロトコル (TCP/UDP) | サービス・用途        | 支援士での出題ポイント・関連トピック                          |
| :---------- | :-------------- | :------------- | :------------------------------------------ |
| **20 / 21** | TCP             | FTP (データ / 制御) | アクティブモードとパッシブモードの通信（20と21の使い分け）             |
| **22**      | TCP             | SSH            | リモートログイン・安全な通信。ブルートフォース攻撃の標的                |
| **23**      | TCP             | Telnet         | 暗号化なしのリモートログイン。盗聴リスクが高いため、原則利用禁止（SSHへの移行）   |
| **25**      | TCP             | SMTP           | メール送信。OP2B（Outbound Port 25 Blocking）の文脈で頻出 |
| **53**      | TCP / UDP       | DNS            | 名前解決。ゾーン転送はTCP、クエリはUDP（UDPのDNSアンプ攻撃にも注意）    |
| **80**      | TCP             | HTTP           | Web通信（暗号化なし）。リダイレクト元として登場                   |
| **110**     | TCP             | POP3           | メール受信（ローカルに保存）                              |
| **123**     | UDP             | NTP            | 時刻同期。NTPリフレクション攻撃（DDoS）の踏み台リスク              |
| **143**     | TCP             | IMAP           | メール受信（サーバー側で管理）                             |
| **443**     | TCP             | HTTPS          | Web通信（TLS暗号化）。Webサイト保護の基本                   |
| **3389**    | TCP / UDP       | RDP            | リモートデスクトップ（RDS）。ランサムウェアやブルートフォースの侵入経路にされやすい |

### 2. セキュリティ・支援士試験で「一歩踏み込んで」出やすいポート

| ポート番号           | プロトコル (TCP/UDP) | サービス・用途                   | 支援士での出題ポイント・関連トピック                                       |
| :-------------- | :-------------- | :------------------------ | :------------------------------------------------------- |
| **43**          | TCP             | WHOIS                     | ドメインやIPアドレスの登録者情報照会                                      |
| **161 / 162**   | UDP             | SNMP / SNMP Trap          | ネットワーク機器の監視・管理。コミュニティ名のデフォルト（public等）脆弱性                 |
| **389**         | TCP / UDP       | LDAP                      | ディレクトリサービスへの問い合わせ                                        |
| **445**         | TCP             | SMB / CIFS                | ファイル共有。WannaCryなどのランサムウェアが好んで狙う（遮断推奨）                    |
| **465**         | TCP             | SMTPS                     | SSL/TLSによるメール送信（Implicit）                                |
| **587**         | TCP / UDP       | Submission                | メール送信（SMTP-AUTH利用。スパム対策・OP2B回避で推奨）                       |
| **636**         | TCP / UDP       | LDAPS                     | SSL/TLSで暗号化したLDAP                                        |
| **989 / 990**   | TCP / UDP       | FTPS                      | SSL/TLSを使ったFTP通信                                         |
| **1812 / 1813** | UDP             | RADIUS (認証・認可 / アカウンティング) | ネットワーク認証の基本プロトコル。UDPを使い暗号化は一部（パスワードのみ）                   |
| **3868**        | TCP / SCTP      | Diameter                  | RADIUSの後継。TCP/SCTPによる信頼性向上と、トランスポート層全体（TLS/IPsec）の暗号化に対応 |
