### 1. 攻撃別の特別な記号例

| 攻撃                                     | 解釈するもの                  | 特別な意味を持つ記号の例                                                                                                                                                                                                                                                  |
| -------------------------------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SQLインジェクション                            | データベース（SQL）             | `'`で文字列を終わらせ、`;`で別の命令を続ける                                                                                                                                                                                                                                     |
| XSS                                    | ブラウザ（HTML・JavaScript）   | `<script>`でスクリプトを始める                                                                                                                                                                                                                                          |
| OSコマンドインジェクション                         | シェル                     | - `;`：コマンドの区切り。`ls; rm file`や`ping 127.0.0.1; cat /etc/passwd`のように、前のコマンドの後に別のコマンドを続けて実行させる。<br>- `$(…)`：コマンド置換。`echo $(whoami)`のように、括弧内のコマンドを実行し、その結果に置き換える。<br>- `${VAR}`：変数展開。`VAR`の部分に任意の変数名が入り、シェルはこれを変数`VAR`の値に置き換える（例 : `${HOME}`、`${USER}`、`${PATH}`） |
| 式言語インジェクション、サーバサイドテンプレートインジェクション（SSTI） | Javaの式言語（EL）、テンプレートエンジン | `${…}`の中が式として評価される                                                                                                                                                                                                                                            |
| Log4Shell                              | Log4j                   | `${…}`がルックアップ（指定された値を探して取得し、その値に置き換える機能）として展開される                                                                                                                                                                                                              |
